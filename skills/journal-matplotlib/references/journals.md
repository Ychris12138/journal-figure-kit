# Journal requirements: source-backed profiles

Checked 2026-10-28. Scope: research main figures unless stated otherwise. Values below are a dated snapshot. Reopen the relevant official source for an actual submission; a production editor's instructions for that manuscript take precedence. `Verified` means the primary source was read, not that every possible requirement was audited. PDF page numbers are **1-based file pages**; printed page numbers are distinguished. Follow links and search the supplied heading/phrase if the site has no stable anchor.

Typography-only follow-up, 2026-10-30: [typography.md](typography.md) and its JSON contain the latest local role sizes and retrieval status. Nature's figure guide and artwork PDF, APS, AIP and ACS were read; NC retains its dated 2019 PDF. PNAS/Science live pages returned 403 in this follow-up. This does not refresh all other submission requirements below.

## Nature

**Verified; stage-specific.**

| Use | Specification | Exact official location |
|---|---|---|
| Initial submission planning | Suggested widths 90 / 180 mm; height up to 170 mm; image RGB, at least 300 dpi; Arial/Helvetica, 5–7 pt at final size | [Initial submission](https://www.nature.com/nature/for-authors/initial-submission), **Figures**, bullets beginning “Provide images” and “Figures are best prepared” |
| Final main artwork | Width 89 / 183 mm; maximum figure height 170 mm, leaving room for the caption | [Building and exporting figure panels](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/), **Figure sizing** |
| Final typography | Body text 5–7 pt; panel labels bold upright lowercase a,b,c at 8 pt; line weights 0.25–1 pt | [Final submission](https://www.nature.com/nature/for-authors/final-submission), **Figures**, paragraph on lettering/panel labels |
| Editable delivery | Preserve text/lines as editable vectors; embed fonts; avoid outlining text | [Preparing figures: our specifications](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/), **Text** / artwork specifications |

Local working choice: body 7 pt, panel 8 pt, 0.6 pt axes and 1 pt curves. The final-submission page mentions a **247 mm page depth**: do not turn this into a 247 mm allowed figure height. Do not merge 90/180 with 89/183 into one “Nature” preset. Extended Data has its own [guide](https://research-figure-guide.nature.com/figures/extended-data-formatting-guidelines/); use that role-specific source instead of main-figure rules.

## Nature Communications

**Partial verification: official indexed text + older official PDF.**

- The official [How to submit](https://www.nature.com/ncomms/submit/how-to-submit), **Figures**, search “A single column width”, lists 88 / 180 mm. The indexed official excerpt was available; opening the live page redirected to an inaccessible identity endpoint on the check date.
- [Brief guide for submission](https://www.nature.com/documents/ncomms-submission-guide.pdf#page=1), PDF **p.1, Figures**, was directly read. It is explicitly dated **2019-05-03**: RGB ≥300 dpi; Arial/Helvetica; optimal text 5–8 pt; editable vector formats include PDF/EPS/SVG. These are an older official baseline, not a verified 2026 rule set.
- Local draft choice: 88 or 180 mm, 8 pt text and bold lowercase panels; height fitted to content. No verified title-specific maximum height or current panel-label point size is asserted here. Reconfirm the live guide/editor instructions before declaring final compliance. Do not substitute Nature's 89/183 mm.

## Physical Review Letters (PRL)

**Verified APS shared style, November 2024 edition.** [APS Journals Style Guide](https://res.cloudinary.com/apsphysics/image/upload/v1736779890/APS_Journals_Style_Guide_Authors_Nov2024_ua91lv.pdf#page=42), **II.S Figures**, PDF **pp.42–44** (printed pp.41–43).

Single column is given as 8.5 cm (also rounded as 3⅜ inches); detailed graphics can use 1.5 or 2 columns. At reproduction size, lettering height and symbol width should be ≥2 mm; data-point diameter ≥1 mm; line width ≥0.5 pt; preferably ≥600 dpi. Label subfigures (a), (b), etc.; axis units in parentheses. Accessible colors and grayscale readability matter.

Local draft choice: 85 mm single width; start near 9 pt type, markers ≥3 pt, then inspect **rendered glyph height**. A 2 mm glyph-height requirement is not equivalent to a 5.67 pt font setting. Obtain the actual wide-figure width from the current manuscript template/production instructions; do not multiply the single width without accounting for the gutter. Older contributor pages say 8.6 cm: keep the edition/source explicit.

Initial and revised submission currently accept a combined PDF; source files requested at acceptance: [Web submission guidelines](https://journals.aps.org/authors/web-submission-guidelines-physical-review), **Uploading Files → File formats**. This submission rule is separate from artwork design.

## Physical Review E (PRE)

**Verified: same shared APS artwork rules and source locator as PRL above.** PRE is a separate selectable journal, sharing this particular source; do not import PRL manuscript length limits. Use the same draft single-column width, actual-height check, (a) labels and line-weight rules. Wide size and final file requests remain manuscript/template-specific.

## The Journal of Chemical Physics (JCP, AIP)

**Verified.** [AIP Author Instructions](https://publishing.aip.org/resources/researchers/author-instructions/), **Preparing Your Graphics → Guidelines**, bullet **For all other journals** (the other branch is JMP, not JCP).

Maximum widths: single 3.37 in / 8.5 cm; double 6.69 in / 17 cm. Maximum depth: 8¼ in / 21.1 cm. These unit pairs are rounded inconsistently; a conservative local choice is **85 / 170 mm width and ≤209.5 mm height**, with caption space allowed. Lettering ≥8 pt; lines ≥0.5 pt; panel labels (a),(b); embedded fonts; prepare at 100% size.

Same page, **Electronic graphic formats**: line art 600 dpi, halftones 264 dpi, combination 600 dpi, online color 300 dpi RGB. **Production-ready PDF graphics**: PDF is not preferred for accepted artwork; PS/EPS/TIFF preferred, with PDF fallback conditions including 600 ppi shaded/photo content and 1200 ppi unshaded raster line art. Preserve editable PDF as a working master and prepare the requested submission format. Do not flatten transparency into EPS silently. **Providing Alt Text** requires alternative text for visual content. Initial manuscript PDF includes figures rather than separate figure uploads.

## The Journal of Physical Chemistry Letters (JPCL, ACS)

**Verified, guide updated 2026-10-08.** [Official author guide PDF](https://researcher-resources.acs.org/publish/author_guidelines/pdf?coden=jpclcd#page=20), **Appendix 2: Preparing Graphics → Resolution / Size / Color**, PDF **p.20**.

Single width ≤240 pt (84.67 mm); double width 300–504 pt (105.83–177.8 mm). Maximum height **including caption** 660 pt (232.83 mm), reserving 12 pt per caption line. Lettering ≥4.5 pt, lines ≥0.5 pt; Arial/Helvetica suitable. Local preferred text is 7–8 pt rather than the minimum. Raster resolutions: black/white line art 1200, grayscale 600, color 300 dpi. Continuous numerical maps still need color-accessibility checks.

TOC graphic is a **separate role**: same PDF **p.1, Table of Contents Graphic**, 3.25 × 1.75 in (82.55 × 44.45 mm). Never use this as the main figure canvas. Initial Fast Format embedding: **p.4, Submit with Fast Format**. Verify accepted file types at the guide's linked software/file-designation page for the actual upload.

## PNAS

**Verified, two official sizing contexts.**

- [Submitting your manuscript](https://www.pnas.org/author-center/submitting-your-manuscript), **Figures**, suggests small 90 × 60, medium 110 × 110, large 180 × 220 mm; text 6–12 pt. These are suggested display sizes, not three mandatory fixed canvases.
- [Digital Art Guidelines](https://www.pnas.org/pb-assets/authors/digitalart-1675347574760.pdf#page=2), PDF **p.2, Sizing tips**, gives production column widths 87 / 114 / 178 mm and recommended maximum height 225 mm. It contains rounded unit equivalents. Local final-layout choice uses these stated metric dimensions, 9 pt axis labels and 8 pt ticks/legends; record this source rather than silently mixing with the web suggestions.
- Same PDF **p.1, Resolution and Raster Images / Color mode**: original RGB; preferred TIFF/EPS/PDF, vectors preferred. Raster photographs ≥300 ppi, combinations 600–900, monochrome line art 1000–1200. Use the upper end when preparing raster submission files. Keep vector content vector. A 600 dpi universal PNG alone is insufficient for all raster types.

Do not confuse PNAS with PNAS Nexus. Resolve production sizing using the editorial instructions/template when they differ.

## Science (AAAS flagship)

**Unverified current production specification; safe draft profile only.** Official [initial manuscript instructions](https://www.science.org/content/page/instructions-preparing-initial-manuscript) and [revised manuscript instructions](https://www.science.org/content/page/instructions-preparing-revised-manuscript) returned HTTP 403 on 2026-10-28. The linked [2025 author guide](https://www.science.org/do/10.5555/page.2385607/full/author_prep_guide_2025-1752841600717.pdf) and [figure guide](https://www.science.org/do/10.5555/page.2385610/full/author_figure_prep_guide_2022-1723557116113.pdf) could not be read either. Exact page/section cannot be certified until retrieved.

Do not promote commonly reposted widths or fonts to verified requirements. For draft work, use a user-specified width and 8 pt type, vector PDF + 600 dpi PNG, uppercase panel labels **as a stated local choice**. Before final delivery, obtain accessible official instructions or the editor-provided document and populate width, height, text, labels, formats and raster resolution with exact locations. Continue independent plot/data work; label unresolved compliance. Never substitute Science Advances' guide or its 90 mm column width for flagship Science.

## Applying a profile without overclaiming

Report a compact line before plotting: journal / stage / role / dimensions / body+panel text / source locator / verification status. Cite the actual source of each override. The inspector checks the explicit dimensions and font bounds supplied to it; it is **not** an automatic publisher certification service. Color/line/normalization preferences are scientific design choices unless the source says otherwise.
